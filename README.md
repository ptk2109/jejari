# 제자리 (Jejari)

macOS 메뉴바 앱. 지금 열린 창의 배치(모니터, 가상화면, 위치, 크기)를 저장해 두었다가, 한 번에 원래 자리로 돌려놓는다.

> 이름의 뜻: 흩어진 창을 늘 있던 "제자리"로.

재부팅하거나 모니터를 뺐다 꽂으면 창이 한 화면에 몰리거나 가상화면 배치가 흐트러진다. 제자리는 기존 창 배치 도구가 하지 못하는 **가상화면(Spaces)까지** 되돌린다.

## 주요 기능

- **저장**: 모든 가상화면의 창을 모아 이름 붙여 저장. 저장할 창을 체크박스로 고른다
- **불러오기**
  - ② 전체 복원: 꺼진 앱을 실행하고, 창을 저장한 모니터·가상화면·위치·크기로 옮긴다. 겹친 순서도 맞춘다
  - ① 배치만: 이미 열린 창만 옮긴다
  - 가상화면이 모자라면 만들고, 모니터가 없으면 비슷한 모니터에 가상화면을 붙여 대신 놓는다
  - Chrome 창은 저장한 탭 주소로, JetBrains IDE는 최근 프로젝트에서 찾아 다시 연다
  - 로그인·인증 창처럼 입력을 기다리는 앱은 뒤로 미루고 다른 앱부터 놓는다
  - 불러오기가 끝난 뒤에 늦게 뜨는 창도 3분 동안 지켜보다가 옮긴다. 가상화면을 바꿔야 하는 창은 작업을 방해하지 않게 알림을 누를 때 옮긴다
- **배치마다 불러올 때 설정**: 배치에 없는 앱(그대로 / 보관 화면으로 / 숨기기 / 종료 요청), 가상화면 맞추는 방식(자동 / 필요한 것만 / 초기화 후 다시 만들기), 남는 가상화면 정리
- **되돌리기**: 불러오기 직전 상태로
- **정리하기**: 🧲 한 화면으로 모으기, 🧹 깨끗하게 비우기
- **설정**: 로그인할 때 실행, 로그인 후 자동 불러오기, 필요한 권한과 macOS 설정 점검(권장값으로 맞춤), 항상 건드리지 않을 앱

## 요구 사항

- macOS 15 이상 (macOS 27.0.1, 27.2에서 확인)
- 손쉬운 사용 권한 (필수), Chrome 탭 주소를 저장하려면 자동화 권한 (선택). 무엇을 왜 쓰는지는 [제자리가 건드리는 것](#제자리가-건드리는-것)

## 설치

1. [Releases](https://github.com/ptk2109/jejari/releases/latest)의 **Assets**에서 `Jejari-<버전>.zip`을 받는다 ("Source code"는 소스 코드라 받지 않는다)
2. zip을 풀고 `Jejari.app`을 **응용 프로그램** 폴더로 옮긴다 ("로그인할 때 켜기"는 이 폴더에 있어야 동작한다)
3. 처음 열 때 "확인되지 않은 개발자" 경고가 뜨면 [완료]를 누르고, 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽의 **그래도 열기** → 다시 뜨는 창에서 **열기** (Apple 공증을 받지 않은 앱이라 처음 한 번 필요하다)
4. 메뉴바에 제자리 아이콘이 생기면 실행된 것이다. Dock에는 아이콘이 없다
   - 아이콘이 ⚠️(세모 느낌표)이면 손쉬운 사용 권한이 아직 꺼져 있다는 뜻이다. 앱 오류나 인증 문제가 아니다. 아래 "처음 설정"대로 켜면 몇 초 안에 원래 아이콘으로 바뀐다
5. 아래 "처음 설정"대로 손쉬운 사용 권한을 켠다

새 버전이 나오면 제자리가 알려 주고 [설치]를 누르면 바뀐다. 손쉬운 사용 권한은 업데이트 뒤에도 그대로다 (설정 → 일반 → 새 버전이 나오면?에서 알아서 설치 / 확인하지 않음으로 바꿀 수 있다).

### 소스에서 빌드

```sh
brew install xcodegen
git clone https://github.com/ptk2109/jejari.git && cd jejari
# 서명 Team (Xcode → 설정 → Accounts의 Apple Development 인증서). 커밋하지 않는 파일
echo 'DEVELOPMENT_TEAM = <Team ID>' > Configs/Signing.local.xcconfig
xcodegen generate
xcodebuild -project Jejari.xcodeproj -scheme Jejari -configuration Release -derivedDataPath build -allowProvisioningUpdates build
open build/Build/Products/Release/Jejari.app
```

같은 Team으로 서명하면 다시 빌드해도 손쉬운 사용 권한이 유지된다.

## 처음 설정

1. 메뉴바 아이콘 → **⚙️ 설정…** → **권한과 macOS 설정** 탭
2. **손쉬운 사용 권한**: [설정 열기] → 목록에서 제자리를 켠다
3. 나머지 항목은 [권장대로]로 맞춘다
   - **Spaces 자동 재정렬 끄기**: 켜져 있으면 가상화면 순서가 저절로 바뀐다
   - **데스크톱 전환 단축키**: 가상화면을 옮길 때 쓴다 (⌃1~⌃0, ⌃⌥1~⌃⌥6. 다른 앱 단축키와 겹치면 주의)
4. Chrome 탭 주소를 저장하려면 처음 저장할 때 뜨는 "Chrome 제어" 요청을 허용한다

필요하면 설정 → **일반**에서:

- **로그인할 때 켜기**: 맥을 켜면 제자리가 메뉴바에 자동으로 뜬다
- **로그인 후 자동 불러오기**: 부팅 직후 고른 배치를 ② 전체 복원으로 불러온다 (앱이 뜰 시간을 기다렸다가)
- **외부 명령**: 단축어나 스크립트에서 `jejari://`로 부를 때만 허용한다

## 제자리가 건드리는 것

제자리는 다른 앱의 창을 옮기는 앱이라 권한이 큽니다. 무엇을 왜 쓰는지 모두 적습니다. 저장·불러오기·정리하기를 누를 때(또는 켜 둔 "로그인 후 자동 불러오기") 말고는 뒤에서 아무것도 하지 않습니다.

### 요청하는 권한

| 권한 | 쓰는 곳 | 왜 |
|---|---|---|
| 손쉬운 사용 (필수) | 다른 앱의 창 목록·제목·위치·크기를 읽고 옮기기, 앱 숨기기, 불러오는 동안 창이 생기는 것을 알림으로 받기 | macOS에서 다른 앱의 창을 옮기는 방법이 이것뿐입니다 |
| | 키보드·마우스 입력 흉내 (아래) | 가상화면 사이로 창을 옮기는 공개된 방법이 없습니다 |
| 자동화 → Google Chrome (선택) | 저장할 때 Chrome 창마다 열린 탭 주소 읽기 | 불러올 때 같은 탭으로 창을 다시 엽니다. 거절해도 나머지는 그대로 됩니다 |
| 로그인 항목 (설정에서 켤 때만) | 맥을 켜면 제자리 실행 | "로그인할 때 켜기" |

화면 기록, 파일 전체 접근, 연락처·위치 같은 권한은 요청하지 않습니다.

### 키보드·마우스 입력 흉내

가상화면을 오갈 때 사람이 하는 동작을 대신 보냅니다. 불러오기·정리하기 중에 화면이 잠깐 움직이는 이유입니다.

- 데스크톱 전환 단축키(⌃1~⌃0, ⌃⌥1~⌃⌥6)를 눌러 가상화면을 바꾼다
- 모니터가 1대일 때는 창 제목 막대를 잡고 단축키를 눌러 창을 다른 가상화면으로 옮긴다
- 가상화면을 만들거나 지울 때 Mission Control을 열고 위쪽 막대를 펼친 뒤 Esc로 닫는다
- 마우스 포인터는 끝나면 원래 자리로 되돌린다

### 바꾸는 macOS 설정

설정 → 권한과 macOS 설정에서 [권장대로]를 누를 때만 바꿉니다.

| 설정 | 바꾸는 값 | 되돌리는 법 |
|---|---|---|
| Spaces 자동 재정렬 | 끈다. 반영하려고 Dock을 다시 시작한다(창 배치는 그대로) | 시스템 설정 → 데스크탑 및 Dock → "최근 사용 내역에 따라 자동으로 Spaces 재정렬" |
| 데스크톱 전환 단축키 | 지금 가상화면 수만큼 켠다 | 시스템 설정 → 키보드 → 키보드 단축키 → Mission Control |

"디스플레이마다 별도 Spaces"는 로그아웃이 필요해서 읽기만 하고 설정 화면만 열어 줍니다.

### 다른 앱에 하는 일

- **실행**: ② 전체 복원에서 배치에 있는데 꺼진 앱을 켜고, 저장해 둔 문서·Chrome 탭·JetBrains 프로젝트를 연다
- **숨기기 / 종료 요청**: 배치 설정에서 "배치에 없는 앱"을 그렇게 골랐을 때, 그리고 🧹 깨끗하게 비우기. ⌘Q와 같은 정상 종료 요청이라 저장 안 한 문서는 각 앱이 묻습니다. 강제 종료는 하지 않습니다. Finder와 "항상 건드리지 않을 앱"은 빼고, 종료 전에 확인 창을 띄웁니다
- **가상화면 지우기**
  - 불러오기에서 가상화면을 초기화할 때: 방식이 "초기화 후 다시 만들기"이거나, "자동"인데 저장한 가상화면을 찾지 못했을 때. 지운 화면의 창은 1번 화면으로 모였다가 제자리로 옮겨집니다
  - 남는 가상화면 정리를 켰을 때: 비어 있는 가상화면만 지웁니다
  - 🧲 한 화면으로 모으기, 🧹 깨끗하게 비우기: 지우기 전에 확인 창을 띄웁니다
  - 전체 화면 앱의 화면과 모니터마다 1번 화면은 지우지 않습니다

### 비공개 API

가상화면 목록과 창이 어느 가상화면에 있는지, 데스크톱 단축키 상태는 Apple이 공개하지 않은 기능(SkyLight)으로 읽습니다. macOS 업데이트로 없어지면 그 기능만 끄고 위치·크기만 복원합니다.

### 읽는 파일

- JetBrains 최근 프로젝트 목록(`~/Library/Application Support/JetBrains/*/options/recentProjects.xml`): 창 제목의 프로젝트 이름으로 프로젝트 폴더를 찾으려고 읽습니다

### 저장하는 것과 네트워크

- 배치 파일에는 창 제목, 열린 문서 경로, Chrome 탭 주소가 들어갑니다. 불러오기 기록을 켜면 기록에도 들어갑니다(기본은 꺼짐). 맥 안(아래 "저장 위치")에만 저장하고 어디에도 보내지 않습니다
- 네트워크는 업데이트 확인에만 씁니다. 하루 한 번 GitHub의 `appcast.xml`을 받아 새 버전이 있는지 봅니다. 사용 기록이나 시스템 정보는 보내지 않습니다. 설정 → 일반 → 새 버전이 나오면? → 확인하지 않음으로 끌 수 있습니다

## 사용법

| 메뉴 | 하는 일 |
|---|---|
| 📸 현재 배치 저장… | 덮어쓸 배치(설정·뺀 창 이어받음) 또는 새 배치를 고르고, 불러올 때 설정과 저장할 창을 골라 저장 |
| 📂 불러오기 ▸ 배치 ▸ ② / ① | 전체 복원 / 배치만 |
| ↩️ 되돌리기 | 불러오기 직전 배치로 (배치만) |
| 🗂 배치 관리… | 이름·설정 수정, 창 고르기, 복제, 여러 개 삭제 |
| 🧰 정리하기 | 한 화면으로 모으기 / 깨끗하게 비우기 |
| 마지막 결과 보기 | 옮긴 창, 문제, 찾지 못한 창 |

스크립트나 단축어에서는 URL로 부를 수 있다. 먼저 설정 → 일반에서 "다른 앱이나 스크립트가 제자리를 부를 수 있게"를 **허용**으로 바꾼다 (기본은 허용 안 함). 가상화면을 지우거나 앱을 끄는 명령은 허용해도 매번 확인 창이 뜬다.

```sh
open "jejari://save?name=회사"
open "jejari://restore?name=회사&mode=full"   # mode=arrange 이면 배치만
open "jejari://undo"
```

결과는 `~/Library/Application Support/Jejari/last-result.json`에 남는다.

## 저장 위치

- 배치: `~/Library/Application Support/Jejari/snapshots/<이름>.json`
- 마지막으로 불러올 때 짝지은 창 번호(다음 불러오기를 정확하게): `~/Library/Application Support/Jejari/matches.json`
- 불러오기 기록(최근 20개): `~/Library/Application Support/Jejari/logs/`. 기본은 남기지 않는다. 불러오기가 이상하면 설정 → 일반 → "불러오기 기록을 남길까요?"를 **남기기**로 바꾸고 한 번 더 불러온 뒤, [기록 폴더 열기]의 폴더를 보내 주면 원인을 찾을 수 있다

## 지우기

1. 메뉴바 아이콘 → **제자리 종료**
2. 응용 프로그램 폴더의 `Jejari.app`을 휴지통으로 옮긴다
3. 저장한 배치와 기록까지 지우려면 `~/Library/Application Support/Jejari` 폴더도 지운다
4. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 목록에 남은 제자리는 [−]로 뺀다
5. 시스템 설정 → 개인정보 보호 및 보안 → 자동화에 남은 제자리, 일반 → 로그인 항목에 남은 제자리도 지운다
6. [권장대로]로 바꾼 macOS 설정을 되돌리려면 [바꾸는 macOS 설정](#바꾸는-macos-설정)의 "되돌리는 법"대로 한다

## 알려진 제한

- macOS는 가상화면을 다루는 공개 기능을 제공하지 않는다. 제자리는 비공개 API(SkyLight, 원격 AX 요소, 가상 모니터)를 쓰므로 **App Store로 배포할 수 없고**, macOS 업데이트 때 동작이 바뀔 수 있다
- 가상화면 순서 자체는 바꿀 수 없어서 창을 옮겨 맞춘다
- 모니터가 1대일 때는 임시 가상 모니터를 거쳐 창을 옮긴다. 이때 화면이 잠깐 깜빡인다
- 불러오는 동안 화면 전환과 키 입력이 있으니 키보드와 마우스를 쓰지 않는다
- 파일을 보여 주던 창, Chrome 창, JetBrains 프로젝트는 다시 열지만, 그 밖에 앱이 스스로 다시 열지 않는 창(메뉴바에서만 여는 창 등)은 열리지 않는다
